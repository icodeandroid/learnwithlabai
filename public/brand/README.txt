LearnWithLabAI — logo files
The Stacked lockup: LEARN WITH above LabAI, with a gold rule beneath.
Type: Space Grotesk (600 / 700), a free Google Fonts typeface. The text is
converted to outlines, so these files render identically anywhere — on a
printer, a client's laptop, or in WhatsApp — with no font to install.

PRIMARY — STACKED  (use this one)
  logo-stacked-dark.svg    — for dark backgrounds (your site, decks)
  logo-stacked-light.svg   — for white/light backgrounds (documents, invoices)
  logo-stacked-white.svg   — all white, for photos or coloured blocks
  logo-stacked-black.svg   — all black, for one-ink print and stamps

SECONDARY — SINGLE LINE  (only where the stacked will not fit: a narrow site
header, an email signature, a social banner)
  logo-primary-dark.svg / -light.svg / -white.svg / -black.svg

AVATAR / PROFILE PICTURE  ("Lab" taken from the wordmark)
  avatar-gold-circle.svg   — WhatsApp Business, LinkedIn
  avatar-plum-circle.svg
  avatar-gold-square.svg   — app icons, social
  avatar-plum-square.svg
  favicon.svg              — browser tab

Every file also has a matching @4x.png with a transparent background, for
anywhere that will not take an SVG (WhatsApp, Word, PowerPoint).

COLOURS
  Gold        #C6A664   "LEARN WITH" and the rule
  Off-white   #F7F3FA   "Lab"
  Lilac       #B98CD8   "AI"
  Plum        #1E1324   background
  On light backgrounds: #8A6A22 gold, #241430 Lab, #6E4A8C AI

USING IT
  Leave clear space around the logo equal to the height of the "L" in Lab.
  Do not stretch it, recolour it, add a shadow, or re-set the name in another
  font. Never put the dark version on a dark background — use the light or
  white file instead. Smallest safe size for the stacked lockup is about 90px
  wide; below that use the single-line version or the avatar.
